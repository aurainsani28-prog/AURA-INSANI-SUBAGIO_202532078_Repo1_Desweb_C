# Kicau Kota

Website statis multi-page tentang pengamatan burung liar di Jakarta. Dibuat untuk Laporan Praktikum 1 mata kuliah Desain Web (HTML5 Fundamentals dan Semantic Form). Murni HTML, belum memakai CSS.

## Struktur

```
kicau-kota/
├── index.html      Beranda
├── spesies.html    Katalog spesies (tabel + profil bergambar)
├── panduan.html    Panduan pengamatan (list + tabel lokasi)
├── lapor.html      Formulir lapor penampakan
└── gambar/         Aset ilustrasi
```

## Cara menjalankan

Buka `index.html` langsung di browser. Tidak perlu server atau instalasi apa pun.
